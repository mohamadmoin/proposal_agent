# The workshop deck

The 66 slides of the 75-minute workshop (version 2: it follows the developer's steps, from the repository to the
build prompt to the release), as the source files of a claude.ai Slides artifact:
- `project/deck.json` is the index;
- `project/slides/*.html` holds one slide per file, with speaker notes and timings in each slide's `<aside>`;
- `img/` holds the screenshots used on slides 51, 59 and 60.

The structure and the teaching tactics are described in `../OUTLINE.md`.

Images on the slides point to the artifact's uploaded copies (`/_blob/…`). To reuse the slides elsewhere, use the
files in `img/`.
