# The workshop deck

The 42 slides of the 75-minute workshop, as the source files of a claude.ai Slides artifact:
- `project/deck.json` is the index;
- `project/slides/*.html` holds one slide per file, with speaker notes and timings in each slide's `<aside>`;
- `img/` holds the screenshots used on slides 33 and 40.

Images on the slides point to the artifact's uploaded copies (`/_blob/…`). To reuse the slides elsewhere, use the
files in `img/`.
