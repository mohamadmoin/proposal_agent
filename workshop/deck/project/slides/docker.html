3 · The stack · Docker

Docker packages the app so it runs the same everywhere

Image: the app and everything it needs, frozen. Container: a running copy. Compose: several containers started together.

Here: one image, three services. No Python or MySQL to install on your laptop.

services:
  db:     # MySQL 8.4, data in a volume
  web:    # migrate, then gunicorn :8000
  worker: # manage.py run_worker

$ docker compose up --build
