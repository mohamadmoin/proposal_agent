Traceability is a research value as much as an engineering one: for any sentence you can find the paper it came from, the score that selected it, the exact prompt and the model’s raw answer. The old tool kept nothing but the final text, so a wrong sentence could not be traced. This is shown in the app’s “How this was made” panel.
