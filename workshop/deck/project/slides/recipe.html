An expert’s background section follows a recipe

1

Search widely

many short searches, not one clever one

2

Screen

read abstracts, drop the unrelated

3

Keep strictly similar

same aim, same design, recent: 5–10

4

Summarise each the same way

author, year, aim, design, population, results

5

Cite precisely

one source per claim, a real reference

Written down, this recipe is knowledge/background_checklist.md in the repository: plain text, edited by clinicians, read by the app.
