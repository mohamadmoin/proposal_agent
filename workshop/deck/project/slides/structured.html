Structured outputs turn the model’s answer into data

You give the API a schema; the answer must fit it. No regex, no “please answer in JSON”.

In this app: screening returns scores and sentence numbers that code can check.

reply = client.chat.completions.parse(
  model=MODEL, messages=messages,
  response_format=ScreeningBatchOut)

batch = reply.choices[0].message.parsed
for paper in batch.papers:
    print(paper.aim_similarity,  # 0–3
          paper.design,         # a label
          paper.evidence)       # [2, 5]

28:00–29:30. Before structured outputs, people asked the model to “reply in JSON” and parsed it with fragile code; the archived first version of this tool did exactly that. Now the schema is enforced. A trick worth remembering: the model answers with sentence NUMBERS as evidence, so code can check the quote exists. A model cannot invent a sentence it can only point at.
