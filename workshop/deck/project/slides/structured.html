Step 2 · §4.3 · structured outputs

Structured outputs turn the model’s answer into data

You give the API a schema; the answer must fit it. No regex, no “please answer in JSON”.

Here: screening returns scores and sentence numbers that code can check.

reply = client.chat.completions.parse(
  model=MODEL, messages=messages,
  response_format=ScreeningBatchOut)

batch = reply.choices[0].message.parsed
for paper in batch.papers:
    print(paper.aim_similarity,  # 0–3
          paper.evidence)       # [2, 5]
