Aims follow a grammar, so hypotheses and questions always match

Aim

تعیین ارتباط شاخص توده بدنی با کم‌خونی فقر آهن در دانشجویان دختر

Hypothesis

بین شاخص توده بدنی و کم‌خونی فقر آهن در دانشجویان دختر ارتباط معناداری وجود دارد.

Question

آیا بین شاخص توده بدنی و کم‌خونی فقر آهن در دانشجویان دختر ارتباط وجود دارد؟

Fixed frames: «مقایسه … میان … و …» for comparisons, «تعیین … در …» for one population. A descriptive aim gets a question but no hypothesis. Code checks that the counts match one to one.
