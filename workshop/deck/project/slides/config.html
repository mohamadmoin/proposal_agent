Settings live in the environment, never in the code

# .env.example (safe defaults)
LLM_PROVIDER=fake     # or openai, gemini
LLM_API_KEY=
LLM_MODEL=
LLM_MODEL_STRONG=
LLM_TEMPERATURE=   # empty: not sent
NCBI_API_KEY=
PUBMED_OFFLINE=1   # demo records
API_TOKENS=

Same code, three settings: your laptop (fake model, saved records), a student’s OpenAI key, DrNext’s Gemini key.

The real .env is in .gitignore. A key pushed to GitHub is found by bots within minutes.

Inside DrNext Academy: no new setting at all. The app reuses the keys the backend already has.
