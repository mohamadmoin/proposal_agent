Facts that must be exact are owned by code, not by the model

The model writes

… was 39.8% among pregnant women. {P1}
… women of reproductive age {S2}{S5}

Code turns it into

… was 39.8% among pregnant women. [7]
… women of reproductive age [2, 3]

  • Citation numbers and the reference list come from PubMed metadata, never from the model
  • Every number in a summary must appear in its abstract, or it is replaced
  • The sample size is computed in Python; the writer must copy the exact number

17:30–19:00. The biggest fear about AI in research is invented references and numbers. The design answer: never let the model own them. It writes tokens; code assigns numbers in order of first appearance across the whole document and builds Vancouver references from PubMed records. Numbers are checked against the source text with a simple, testable function.
