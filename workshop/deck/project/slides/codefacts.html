The model can point at sentences, but cannot invent them

Evidence by number

code: sentence 2 exists ✓ numbers present ✓

Citations by token

model: … 3.8 percent. {P1}
       … women of reproductive age {S2}{S5}
code: … 3.8 percent. [8]
      … women of reproductive age [2, 3]

Numbers are assigned once, in order of first appearance across the whole document; references are built from PubMed records. The biggest fear about AI in research — invented references — is designed out.

Two tricks worth stealing for any AI tool in medicine. 1) Ask for evidence as sentence numbers, then check them in code: a model cannot fabricate a sentence it can only point at. 2) Let the model write tokens, never numbers; code numbers the references.
