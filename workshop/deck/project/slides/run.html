Run it on your laptop in three commands, no key needed

git clone https://github.com/mohamadmoin/proposal_agent.git && cd proposal_agent
cp .env.example .env
docker compose up --build    # then open http://localhost:8000

Demo mode

A fake model and saved PubMed records: every step runs, offline.

Real mode

Put an OpenAI or Gemini key in .env and set PUBMED_OFFLINE=0.
