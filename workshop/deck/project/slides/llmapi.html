3 · The stack · LLM API

An LLM API is a function you call over the internet

You send messages (a system prompt and the task), the provider sends back text. You pay per token: roughly ¾ of a word.

In this app: one client for OpenAI, Gemini or a fake model; switched by an environment variable.

client = OpenAI(api_key=KEY, base_url=URL)

reply = client.chat.completions.create(
  model="gpt-5.4-mini",
  messages=[
    {"role": "system", "content": persona},
    {"role": "user", "content": task}],
  reasoning_effort="none")

print(reply.choices[0].message.content)
