Step 2 · §4.3 · the LLM API

An LLM API is a paid function you call over the internet

You send messages (a system prompt and the task); you get text back; you pay per token, about ¾ of a word.

Here: one client for OpenAI, Gemini or a fake model. In DrNext Academy it uses Gemini first and OpenAI if Gemini fails.

client = OpenAI(api_key=KEY, base_url=URL)

reply = client.chat.completions.create(
  model="gpt-5.4-mini",
  messages=[
    {"role": "system", "content": persona},
    {"role": "user", "content": task}],
  reasoning_effort="none")
