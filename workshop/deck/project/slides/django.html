Django gives you a web app, an admin and a database layer in one

  • Models: tables as Python classes
  • Views: what a URL returns
  • Admin: a free back-office
  • Migrations: database changes as files
  • django-ninja: a JSON API from Pydantic schemas, with docs at /api/docs
