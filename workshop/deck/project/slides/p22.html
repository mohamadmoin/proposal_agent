aim_similarity (0–3): 0 = unrelated, 1 = same topic but a different question, 2 = similar aim, 3 = same aim and main outcome … Score = 3·aim + 1·population + 2·design_match + recency (2 within 5 years, 1 within 10) … If fewer than 5 qualify, never add papers with aim ≤ 1. Tell the user.

  • The model scores; code selects with a formula a supervisor would sign
  • Evidence = numbered abstract sentences, checked to exist
  • Every number in a finding must appear in the abstract
  • One paragraph per paper, from that paper’s abstract only
