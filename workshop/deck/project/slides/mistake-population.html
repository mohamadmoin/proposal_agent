Lab notebook · mistake 2 · sample size

A prevalence from pregnant women sized a study of students

We assumed

The most similar study — ranked by aim — is the best source for the numbers. The notes step took baseline numbers from the top background papers.

The run showed

p = 39.8% — iron-deficiency anaemia in pregnant women in Fuyang, China — sized a study of female university students in Tehran: n = 369.

Why it was wrong

A sample-size parameter must come from a population like the study’s. Pregnancy raises iron needs; prevalence differs widely between groups. Similar aim is not similar population.

The fix

Each number carries its paper’s population similarity. Prompt: “choose the most similar population, then the same country, then the most recent”. Code prints a note when the source population may differ, so the researcher checks it.
