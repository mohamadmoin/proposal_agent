# Case-control study (STROBE)

When to read: after choosing a case-control design, before the sample size and the methods.
How to use: decide each item (record_decision for case definition, control source, matching, primary exposure).

Essentials of the protocol
- Case definition with explicit diagnostic criteria (e.g. IADPSG 75 g OGTT: fasting ≥ 92, 1 h ≥ 180, 2 h ≥ 153 mg/dL)
  and where/when cases are recruited (incident cases preferred).
- Controls from the same source population as the cases, with the same exclusions; the control:case ratio.
- Matching: either unmatched, or matched on named factors that are NOT exposures of interest; a matched design needs a
  matched analysis (conditional logistic regression) and a matched sample-size formula. Never "matched" without naming
  the variables.
- Primary exposure named; the sample size is calculated for that exposure.
- Exposure measurement the same way for cases and controls (records or interview with the same instrument), with
  recall-bias control.
- Sample size: p0 = exposure prevalence in controls and the minimum OR worth detecting, from a comparable population;
  both values tied to the primary exposure.
- Analysis: OR with 95% CI, multivariable logistic regression (or conditional for matched), confounders named, model
  building rule.

Pitfalls seen in reviews
- Matching on a variable that is also an objective (its effect can no longer be estimated).
- Matched design with an unmatched formula or analysis, or "matched" without variables.
- Sample-size parameters for an exposure that is not an objective.
- Exposures that only make sense for multiparous women applied to all women.
