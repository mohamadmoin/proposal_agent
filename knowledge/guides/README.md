# Guides for the agentic engine

Short, agent-oriented summaries written for this project, served by the agent's `read_guide` tool. They summarise in
our own words what the published reporting guidelines expect from a protocol of each design (EQUATOR Network:
https://www.equator-network.org); they are not copies of the checklists. Each file starts with "When to read" and "How
to use". Owner decision DEC-A4: no external review step; the agent is told when and how to use each guide.

| file | read before |
|---|---|
| design_cross_sectional.md | writing methods of a cross-sectional study (STROBE) |
| design_cohort.md | writing methods of a cohort study (STROBE) |
| design_case_control.md | writing methods of a case-control study (STROBE) |
| design_rct.md | writing methods of a randomised trial (SPIRIT for protocols, CONSORT) |
| design_quasi_experimental.md | writing methods of a non-randomised intervention study (TREND) |
| design_diagnostic.md | writing methods of a diagnostic-accuracy study (STARD) |
| design_systematic_review.md | writing methods of a systematic review protocol (PRISMA-P) |
| design_qualitative.md | writing methods of a qualitative study (COREQ / SRQR) |
| sample_size_principles.md | choosing the sample-size formula and parameters |
| ethics.md | writing the ethics part (every proposal) |
| consistency_checklist.md | the final check before finishing (every proposal) |
