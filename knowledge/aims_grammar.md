# Aims, hypotheses and questions: a grammar

The aims section is generated from the study's variables with fixed sentence frames, so the aims, hypotheses and
questions always match one to one.

1. **Main aim**: the study title, rewritten as an aim («تعیین …» / "To determine …").
2. **Secondary aims**: one sentence per variable of interest.
   - The variable is **compared between groups** →
     - fa: «مقایسه [نام متغیر] میان [گروه ۱] و [گروه ۲]»
     - en: "To compare [variable] between [group 1] and [group 2]"
   - The variable is **evaluated in one population** →
     - fa: «تعیین / ارزیابی وضعیت [نام متغیر] در [جمعیت مورد مطالعه]»
     - en: "To determine [variable] in [study population]"
   - The variable is **followed over time** →
     - fa: «بررسی تغییرات [نام متغیر] در [جمعیت] طی [زمان]»
     - en: "To assess changes in [variable] in [population] over [time]"
   - The **relationship** between two variables →
     - fa: «تعیین ارتباط [متغیر ۱] با [متغیر ۲] در [جمعیت]»
     - en: "To determine the association between [variable 1] and [variable 2] in [population]"
   The population name comes from the title.
3. **Hypotheses**: each secondary aim rewritten as a testable hypothesis, in the same order. Descriptive aims (a single
   population, no comparison) do not need a hypothesis. For those, write the question form instead and mark the
   hypothesis as not applicable.
4. **Research questions**: each secondary aim rewritten as a question, in the same order.
5. **Practical aims (applications)**: who can use the results and how (clinicians, policy makers, further research).

Rule checked by code: the number of secondary aims = the number of questions = the number of hypotheses (counting the
"not applicable" entries).
